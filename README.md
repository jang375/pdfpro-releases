# PDF Pro 설치

사내용 PDF 보기·편집 프로그램입니다. (Windows 10/11)

## 설치 방법

1. 오른쪽 **Releases**에서 가장 최신 버전을 누릅니다.
2. **`PdfPro-win-Setup.exe`** 를 내려받아 실행합니다. (관리자 권한 필요 없음)
3. 바탕화면의 **PDF Pro** 아이콘으로 실행합니다.

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

## 업데이트

새 버전이 나오면 프로그램 위쪽에 알림이 뜹니다. **지금 다시 시작해서 업데이트**를 누르거나,
그냥 두면 프로그램을 끌 때 자동으로 적용됩니다. 바뀐 부분만 내려받아 금방 끝납니다.
